## 📋 주요 내용

- **비소세포암(NSCLC)** 세포형별 바이오마커 우선순위
  - 선암종 (Adenocarcinoma)
  - 편평세포암종 (Squamous Cell Carcinoma)
  - 대세포암 / NOS (Large Cell / Not Otherwise Specified)
- **소세포암(SCLC)** 진단·표적치료·면역 바이오마커
- 각 바이오마커별 **변이유형별 1차 표적치료제**
- **PCR / FISH / IHC / NGS** 검사법 특성 비교
- 드라이버 돌연변이 / 면역·예측 바이오마커 개념 설명

## 🚀 GitHub Pages 배포 방법

1. 이 저장소를 GitHub에 업로드
2. **Settings → Pages → Source** 에서 `main` 브랜치, `/ (root)` 선택
3. **Save** 클릭
4. 약 1~2분 후 `https://<username>.github.io/<repo>/` 접속
